# Code of conduct

This project welcomes contributions from anyone. In issues, pull requests and
discussions we expect people to:

- Be respectful. Disagree with ideas, not with people.
- Assume good intent, and ask before concluding.
- Keep feedback specific and about the work.
- Respect the maintainer's decisions on scope. A "no" to a feature is not a
  judgment of the person proposing it.

Harassment, personal attacks, discriminatory remarks and publishing someone's
private information are not tolerated. The maintainer may edit, hide or delete
content and block accounts that break these rules.

To report a problem, email the maintainer through the address on the
[kreeptales](https://github.com/kreeptales) GitHub profile, or use GitHub's
report feature on the content itself.
